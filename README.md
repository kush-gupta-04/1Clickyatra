# 🌍 1ClickYatra - Travel & Tourism Booking Platform

1ClickYatra is a modern full-stack travel and tourism booking platform built using the **MERN Stack**. It allows users to explore travel destinations, browse tour packages, read travel blogs, submit inquiries, and book their dream vacations through a clean and responsive interface.

---

## 🚀 Features

### 👤 User Features
- Browse featured travel packages
- Search and explore destinations
- View package details
- Read travel blogs
- Submit travel inquiries
- Contact support
- User Authentication (JWT)
- Responsive UI for all devices

### 🔐 Admin Features
- Secure Admin Authentication
- Manage Tour Packages
- Manage Blogs
- View Customer Bookings
- Handle Customer Inquiries
- Manage Testimonials

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/1ClickYatra.git
```

---

### Install Frontend

```bash
cd Client
npm install
npm run dev
```

---

### Install Backend

```bash
cd Server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **Server** folder.

```env
PORT=5001

MONGO_URI=mongodb://localhost:27017/tourism-booking

JWT_SECRET=your_secret_key

JWT_EXPIRES_IN=7d

CLIENT_URL=http://localhost:5173
```
